# Neues C# Projekt anlegen und ausführen

1. **VS Code** öffnen
2. **Open Folder**: Öffne den Ordner, in dem du alle deine C#-Programme speichern willst.
3. **Neues Terminal** öffnen und folgenden Befehl eingeben: `dotnet new console -n "NameDeinesProgramms"`
4. **Open Folder**: Öffne deinen Programm-Ordner
5. **Neues Terminal** öffnen und Programm ausführen mit: `dotnet run`
6. Wenn du alles richtig gemacht hast, erscheint nun `Hello, World!`im Terminal.
7. Schreibe den Code deines Programms nun in die Datei **Program.cs**


## Fehler *Anwendungsrichtline*

Wenn dein Programm beim Ausführen den Fehler zeigt **"Eine Anwendungsrichtline hat dein Programm blockiert"**, hast du zwei Möglichkeiten:

1. Deaktivere die **Smart App Control**
2. Speichere deine C# Projekte in einem **lokalen Ordner** (z.B. C:\M319) (nicht OneDrive!!!)
